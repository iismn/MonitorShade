화면 보호

선택한 모니터의 화면 내용이 대기 시간 동안 바뀌지 않으면 그 화면만 검게 가립니다. 마우스가 들어오거나 뒤쪽 화면이 바뀌면 해제합니다. 마우스가 있는 화면은 가리지 않으며, 다른 화면의 감시는 계속됩니다.

배경화면 움직임 무시를 켜면 Lively 같은 움직이는 배경화면과 앱 주변에 노출된 바탕화면 영역을 비교에서 제외합니다. 실제 앱 창 안의 변화는 계속 감지합니다.

Ctrl + Alt + F9 / F10으로 지정한 모니터를 강제로 가립니다. 마우스가 해당 화면에 들어오면 해제되며, 이미 마우스가 있으면 밖으로 나갔다 들어올 때 해제됩니다. 같은 단축키를 다시 눌러도 해제할 수 있습니다.

설정 창을 열면 감시를 일시정지합니다. ‘감시 시작’을 누르면 설정을 저장하고 트레이에서 감시를 이어갑니다. 모니터가 재연결되면 저장한 대상을 찾아 자동으로 감시를 재개합니다.

밝기와 단축키

DDC/CI 표준 밝기 명령(0x10)으로 모니터를 조절합니다. 모니터 OSD의 DDC/CI가 켜져 있어야 하며 HDR이나 특정 화면 모드에서는 조절이 제한될 수 있습니다.

‘함께 조절’은 선택한 모니터에 동일한 값을 적용합니다. 밝기가 40%, 60%일 때 +5를 누르면 둘 다 65%가 됩니다. 동기화를 켜면 개별 슬라이더와 단축키도 연결된 모니터에 같은 값을 적용합니다. 꺼도 ‘함께 조절’은 선택한 모니터를 같이 조절합니다.

슬라이더에 마우스를 올리면 은은하게 밝아집니다. 실제 밝기는 드래그, 방향키, 마우스 휠 또는 +/−로 변경합니다. 휠 한 칸은 2%입니다.

밝기 단축키는 기본 오른쪽 Alt + F2 / F3입니다. 한국어 키보드에서 오른쪽 Alt가 한/영 키로 동작하면 단축키 탭에서 보조키를 변경하세요. Ctrl+Alt·AltGr의 F9~F12는 공통 단축키로 예약되어 있습니다.

nit는 Windows가 보고한 피크·전체 화면 휘도 메타데이터입니다. 현재 밝기의 실측값이 아니며 %를 nit로 환산하지 않습니다.

창 배치와 크기 조절

Win + 방향키를 반복해서 누르면 해당 방향 기준으로 ½ → ⅔ → 전체 작업 영역으로 순환합니다. Win + Del은 설정한 너비의 16:9 중앙 창 → 전체 작업 영역으로 순환합니다. 작업 표시줄은 제외합니다.

Win + Backspace는 현재 모니터 작업 영역의 가로·세로를 각각 50% → 70% → 100%로 순환합니다. 50%와 70%는 중앙 정렬이고 100%는 최대화입니다. 가로·세로 모니터 모두 해당 작업 영역의 비율을 유지합니다. 다른 배치 단축키를 누르거나 창을 직접 옮기고 크기를 바꾸면 다음 순환은 처음부터 시작합니다.

Windows의 기본 Win + 방향키 동작을 대신합니다. 창 배치 기능을 끄면 기본 동작으로 돌아갑니다. 관리자 권한 앱이나 최소 크기 제한이 있는 일부 창은 배치가 제한될 수 있습니다.

실행 및 공통 단축키

Ctrl + Alt + F11 · 설정 열기
Ctrl + Alt + F12 · 화면 보호 일시정지 / 재시작

트레이 아이콘을 두 번 클릭해도 설정을 열 수 있습니다. X 버튼은 트레이로 숨기며, 완전히 종료하려면 왼쪽 아래 ‘종료’를 사용하세요. 로그인 시 자동 실행을 켜면 창 없이 실행하고 저장한 설정으로 감시를 시작합니다.

설정은 EXE 옆의 MonitorShade.settings.xml에 보관합니다. 화면 비교는 메모리에서 처리하며 저장하거나 전송하지 않습니다. 잠금·화면보호기·절전 중에는 조용히 대기합니다. 직접 일시정지한 경우에는 자동으로 감시를 재개하지 않습니다.

화면 공유에는 검은 오버레이 대신 뒤쪽 내용이 보일 수 있습니다. DRM 영상·독점 전체 화면·보안 화면은 변화 감지가 제한될 수 있습니다.

외형과 렌더링

아침 9시의 흰색·살구빛, 낮의 옅은 세이지, 저녁의 올리브색으로 색상이 이어집니다. 일반에서 고정 색상도 선택할 수 있습니다.

설정 화면은 Chromium 기반 WebView2가 그립니다. 한글은 내장 Pretendard, 숫자는 Manrope를 사용합니다. Windows DWM Acrylic이 창 뒤를 실시간으로 흐리게 처리하며, 배경 캡처용 보조 창은 만들지 않습니다.

Windows 11 22H2 이상에서 시스템 투명도 효과가 켜져 있어야 Acrylic이 적용됩니다. 지원되지 않거나 고대비 모드이면 단색 배경으로 표시합니다. WebView2 Runtime이 필요하며 실행 중인 버전은 Microsoft Edge와 함께 관리됩니다.
